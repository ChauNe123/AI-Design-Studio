# 06 — USER REQUIREMENTS

Tổng hợp các yêu cầu cốt lõi đã thực hiện trong `D:\AI_Design_Studio\`:
1. Dự án độc lập hoàn toàn trên ổ `D:\` (`D:\AI_Design_Studio\`), không nằm chung trong `D:\AI\TESTER\`.
2. Ứng dụng Windows chạy độc lập với giao diện trực quan 9 khu vực (Dashboard, MODE A Redesign, MODE B Generate, Layer Editor, Asset Library, Design Knowledge, Project History, Export PSD & QA, Settings).
3. MODE A tách được ảnh phẳng thành các layer độc lập, giữ bố cục gốc, xử lý nền và đánh dấu vùng AI tái tạo (`ai_reconstructed`).
4. MODE B giữ nguyên pixel ảnh sản phẩm thương mại gốc, tạo ánh sáng & bóng đổ tách lớp riêng, sinh Text Layer theo Brand Knowledge.
5. Xuất file `.psd` nhiều layer chuẩn, có kiểm duyệt QA 3 cấp trước khi bàn giao.
